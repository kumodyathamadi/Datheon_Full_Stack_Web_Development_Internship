# Datheon Full Stack Web Development Internship

A collection of web development projects completed as part of the Datheon Full Stack Web Development Internship.

## Projects

### Task 1 — Developer Portfolio
A responsive personal portfolio featuring projects, technical skills, navigation, and a light/dark theme.

**Technologies:** HTML, CSS, JavaScript

### Task 2 — Productivity Task Manager
A responsive task management application supporting task creation, editing, deletion, categories, completion status, filters, and local storage persistence.

**Technologies:** HTML, CSS, JavaScript, LocalStorage

### Task 3 — Live Weather Application
A weather dashboard that retrieves current weather conditions and a five-day forecast for searched cities using a weather API.

**Technologies:** HTML, CSS, JavaScript, Fetch API, OpenWeatherMap

### Task 4 — E-commerce Storefront
A responsive online storefront with API-driven product listings, search, category filtering, sorting, a persistent shopping cart, and simulated checkout.

**Technologies:** React or JavaScript, CSS, FakeStoreAPI, LocalStorage

## Repository Structure

- `Task-1-Portfolio/` — Developer portfolio
- `Task-2-Task-Manager/` — Productivity task manager
- `Task-3-Weather-App/` — Weather dashboard
- `Task-4-Ecommerce-Store/` — E-commerce storefront

## Running the Projects

Each project is maintained in its own folder and may have its own setup instructions.

- For standalone HTML/CSS/JavaScript projects, open `index.html` or use a local development server.
- For React/Vite projects, navigate to the relevant folder, install dependencies with `npm install`, and start the development server using `npm run dev`.
- For the weather application, configure the required API key using the instructions in that project's README.

## Notes

- Weather information requires a valid API key and internet access.
- The e-commerce checkout is a demonstration and does not process real payments.
- See each project's README for detailed setup instructions.
